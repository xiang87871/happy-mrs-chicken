## ✨ 玩法亮点

1. **🥚 活起来的草地游乐园**
   - 点草地任意位置，快乐小鸡跑过去下蛋；普通蛋约 2.8 秒摇晃后自动孵出散步小鸡。
   - 彩虹金蛋需用右下角 **🔨 玩具小锤子**（拖砸或点锤敲一下）砸开盲盒，随机孵出 **24 只手绘稀有小伙伴**（脚下绘本柔雾短名 + 互动头顶自我介绍气泡）。
   - 所有小鸡和稀有小伙伴都支持 **抓起拖拽去玩**：丢进扩大版 **大泥坑** 蹦跳溅泥花、拖上 **🌈 彩虹滑滑梯**「咻——」滑下、放上 **🍄 蘑菇蹦蹦床** 连蹦飞高高！
   - 点云朵切换互动天气：**晴天 → 下雨（泥坑变大）→ 雨后彩虹**。
2. **🎨 颜色启蒙**（双娃兼顾）：`🥚 基础配对`（给妹妹）、`🎨 调色魔法`（Lv.1→Lv.2）、`🚂 规律火车`（ABAB/ABC/AABB）
3. **🌽 数学成长**：`🌽 喂玉米 1–8`、`📏 大小排队`（Lv.1 找小窝 → Lv.2 从小到大排排队）、`➕ 具象小加减`（5 以内加法/减法 → 8 以内混合）
4. **🧩 形状空间**（双娃兼顾）：`🥚 基础`（给妹妹）、`🕵️ 多维线索`、`🧩 图形拼图`（6 套几何蓝图）、`🔎 找不同`
5. **🎵 快乐乐园**：
   - `🎹 音乐小鸡琴`：7 音彩虹小鸡琴（自由弹 + 内置示范播放器 + 星星跟弹《小星星》《两只老虎》《粉刷匠》）
   - `🛁 生活好习惯剧场`：全手感拖拽版 **《洗泡泡澡》**（选泡泡口味→海绵搓泥点+肚子挠痒痒+戳浮空泡泡→花洒淋水甩干→吹风机吹蓬松） & **《刷牙盖被子》**（挤彩色牙膏→大嘴特写刷跑 6 只蛀牙小怪兽+拖水杯漱口→选陪睡玩偶+手指上拉盖星空被→往下拉灯绳关灯摇篮曲）
6. **👗 专属成长与家长助手**
   - **7 大品类 × 6 单品 = 42 件手绘实时穿戴换装间**（同品类自动替换、跨品类自由叠穿、随机穿搭）
   - **4 大主题 × 6 角色 = 24 只手绘稀有小鸡图鉴**
   - **⚙️ 家长小助手**：宝贝专属小名定制、中/英/双语语音、护眼晚安定时（2 秒长按防误触解锁）、爸爸妈妈本地原声配音包、纯本地成长学习报告（100% 本地 `localStorage`，零上传）。

## 🛠️ 项目结构与本地打包

```text
happy-mrs-chicken/
├── index.html          # PWA 主入口
├── manifest.json       # PWA 清单
├── icon.svg            # 应用图标
├── sw.js               # 联网优先 + 离线缓存 Service Worker
├── build.mjs           # 零依赖单文件打包脚本
├── css/
│   ├── base.css        # 全屏绘本世界、响应式导航与弹窗样式
│   └── games.css       # 各玩法组件与像素级点选样式
├── js/                 # 18 个独立功能模块（零构建，直接运行）
└── dist/
    └── happy_mrs_chicken.html  # 自动打包的单文件离线版
```

修改源码后，运行以下命令即可同步更新单文件离线版：

```bash
node build.mjs dist/happy_mrs_chicken.html
```
